2 · Save it as a version

The store already holds version 1. Save the definition on the left over it and it works out, question by question, what changed — and an attribute belongs to the form, so a question that is still being asked keeps its column and every answer already in it.

3 · Fill it in, and watch each answer land

This form is rendered from the version the store is on, not from the editor — answers go into that version. Rename a question, type a key by hand, add one the form does not ask: every answer says which column it reached and which rung of the ladder found it.

4 · The measurement

The same hundred and twenty submissions, stored three ways, asked the same eight questions. Not speed — whether the answer is right, and whether a wrong answer announces itself. Every figure here is what npm run measure prints, computed the same way.

Every form, every question and every submission in this repository is invented. No clinic, no patient and no real form appears anywhere in it. Nothing is written to disk: the store is in memory and goes when this process stops.
